## 2. 2D エディタ

描画キャンバスの操作です。左のパレットで選んだツールによって、同じ操作の意味が変わります。ツールは 5 種類あります: 結合ツール（単結合・二重結合・三重結合・楔・破線楔・波線のボタンはどれも結合ツールで、引く結合の種類が違うだけ）、選択ツール、消しゴム、矢印ツール（反応矢印・平衡矢印）、テキストツール。

### 2.1 用語

| 用語 | 意味 |
| --- | --- |
| ホバー | マウスポインタの下にある原子・結合・オブジェクト（矢印、テキスト、括弧、表）。原子、オブジェクト、結合の順に優先されます。 |
| ホットスポット | キーボード操作の対象になっている原子。クリックやキーで原子を置いたり伸ばしたりすると、新しい原子に移ります。 |
| 結合ターゲット | キーボード操作の対象になっている結合。結合ツールで `Shift`+矢印キーを押して決めます。 |
| 選択 | 選択ツールのクリックや囲み選択で選んだ原子・結合・オブジェクト。 |

### 2.2 どのツールでも効く操作

#### マウス

| 操作 | 条件 | 効果 |
| --- | --- | --- |
| ホイール | ポインタがキャンバスの上 | 拡大・縮小（ポインタの位置が中心） |
| `Ctrl`+ホイール、ピンチ | ポインタがキャンバスの上 | 拡大・縮小 |
| 中ボタンでドラッグ | 入力欄が開いていない、整形の実行中でない | 表示の移動 |
| 右クリック | 結合の上 | 結合の種類・二重結合の位置・削除のメニュー、3D 化、書式（色・影など） |
| 右クリック | 結合以外 | 3D 化、書式のメニュー。対象は、選択があれば選択した分子、なければクリックした分子、何もない所なら図全体 |

#### キー

「入力中」の列は、ラベル・テキスト・表のセル・角度の入力欄や、ほかのパネルの文字入力欄にカーソルがある間にどうなるかです。

| キー | 効果 | 入力中 |
| --- | --- | --- |
| `Ctrl`+`Z` | 元に戻す。整形の実行中は整形を取り消して開始前に戻す | テキスト・表のセル・角度の入力欄では、欄の中の入力を戻す。ラベルの入力欄とほかのパネルの入力欄では、キャンバスの編集が戻る |
| `Ctrl`+`Y`、`Ctrl`+`Shift`+`Z` | やり直す | 同上 |
| `Ctrl`+`C` | コピー。選択がなければ図全体 | 無効（欄の中の文字のコピーになる） |
| `Ctrl`+`X` | コピーと同じ。切り取られない | 無効（欄の中の文字の切り取りになる） |
| `Ctrl`+`V` | 貼り付け | 無効（欄への貼り付けになる） |
| `Ctrl`+`0` | 図全体が収まるように表示。同時に UI 倍率が 100% に戻る（[6.2](#62-ui-の倍率)） | 全体表示は無効。UI 倍率は戻る |
| `Ctrl`+`1` / `2` / `3` | 選択ツール / 結合ツール / 消しゴムに切り替え | 有効 |
| `Ctrl`+`K` | 整形（クリーンアップ）の開始・停止。原子や結合を選択していれば、その部分だけを整形 | 有効 |
| `Ctrl`+`Shift`+`K` | 反応式の整形（矢印は動かさず、構造を整えて並べ直す） | 有効 |
| `Ctrl`+`R` | 角度の入力欄を開く（[2.6](#26-入力欄)）。原子を 2 個以上選択しているときだけ | 無効 |
| `Ctrl`+`Shift`+`F` | 選択を反転。原子を 2 個以上選択し、選択の内と外をつなぐ結合がちょうど 1 本のときだけ。楔と破線楔は立体配置が保たれるように入れ替わる | 無効 |

矢印ツールとテキストツールに切り替えるキーはありません（パレットか「反応」メニューから）。

### 2.3 結合ツール

#### マウス

| 操作 | 条件 | 効果 |
| --- | --- | --- |
| クリック | 何もない所 | 原子を置く（パレットで選んでいる元素） |
| クリック | 原子の上 | その原子から結合を 1 本伸ばす。伸ばした先に原子があればそれとつなぎ、すでに結合があれば次数を変える |
| クリック | 結合の上、単結合・二重結合・三重結合のボタンを選択中 | 結合次数を 単 → 二重 → 三重 → 単 と切り替える |
| クリック | 単結合の上、楔・破線楔・波線のボタンを選択中 | その種類の結合に置き換える。楔の細い側は、クリックした位置に近い原子 |
| クリック | 選択中の種類と同じ種類の結合の上 | 楔・破線楔は向きを逆にする。波線は普通の単結合に戻す |
| クリック | 二重結合・三重結合の上、楔・破線楔・波線のボタンを選択中 | 結合次数を切り替える（種類は置き換えない） |
| ドラッグ | 原子の上から | 結合を引く。離した所に原子があればそれとつなぎ、なければ新しい原子を置く |
| ドラッグ | 原子から、すでに結合している隣の原子まで | その結合に、クリックと同じ操作をする。楔の細い側はドラッグを始めた原子 |
| ドラッグ | 何もない所から | 囲んで選択（選択ツールと同じ） |
| ドラッグ | 結合の上から | 何もしない |

#### キー

文字キーは、`Ctrl` や `Alt` を押している間と、押しっぱなしの自動連打では効きません。矢印キーは自動連打でも効きます。

| キー | 条件 | 効果 |
| --- | --- | --- |
| `Delete` / `Backspace` | ホバーまたはキーボードの対象がある | 削除。優先順は、ホバー中の原子、オブジェクト、結合、結合ターゲット、ホットスポット。選択した原子は削除されない |
| `Enter`、`g`、`G` | 原子をホバー中 | その原子をホットスポットにする |
| `Space`、`Tab` | | ホットスポットと結合ターゲットを解除 |
| 矢印キー | ホットスポットあり | その方向の隣の原子にホットスポットを移す |
| 矢印キー | ホットスポットなし | キーで原子を置く位置を、結合 1 本ぶん動かす |
| `Shift`+矢印キー | ホットスポットあり | その方向の隣の原子との結合を、結合ターゲットにする |
| `` ` ``（バッククォート） | 原子をホバー中、またはホットスポットあり | ラベルの入力欄を開く（[2.6](#26-入力欄)） |
| `x`、`X` | 原子をホバー中、またはホットスポットあり | ラベルが断片名（`Boc`、`Ph` など。`MeOPh` のようにつなげた名前も可）なら、その構造に展開 |
| 文字・数字キー | 下の「キーの対象の決まり方」を参照 | [原子キー](#原子キー) または [結合キー](#結合キー) |

#### キーの対象の決まり方

文字・数字キーを押したとき、何に作用するかは次の順で決まります。

1. 原子をホバーしている → その原子に [原子キー](#原子キー) を適用。
2. 原子をホバーしていなくて、キーが「元素を置くキー」（原子キーの表で ● を付けたもの）→ ポインタの位置に、その元素の原子を 1 個置く。ポインタがキャンバスの外にあって、ホットスポットがあるときは、この手順は飛ばす。
3. 結合をホバーしている、または結合ターゲットがある → その結合に [結合キー](#結合キー) を適用。
4. ホットスポットがある → その原子に原子キーを適用。

2 が 3 より先なので、マウスで結合をホバーしているときは、元素を置くキーでもある `w`、`h`、`b`、`B`、`d`、`9` は結合キーとしては働かず、ポインタの位置に原子が置かれます。`Shift`+矢印キーで決めた結合ターゲットに対しては（ポインタがキャンバスの外なら）結合キーとして働きます。

#### 原子キー

大文字は `Shift` を押しながらです。● は「元素を置くキー」でもあるもの（上の手順 2）。

| キー | 原子への作用 | ● |
| --- | --- | --- |
| `0`、`1` | 炭素を 1 個伸ばす | |
| `3` | 炭素を 3 個伸ばす | |
| `z` / `Z` | ジグザグの鎖を 2 個 / 4 個伸ばす | |
| `v` | 三員環 | |
| `4`、`u` | 四員環 | |
| `5` / `6` / `7` / `8` | 五 / 六 / 七 / 八員環 | |
| `a`、`P` | ベンゼン環 | |
| `2` | オキソ基（=O） | |
| `c`、`m` | Me（炭素 1 個） | ● |
| `e` | Et | |
| `A` | Ac | |
| `E` | CO₂Me | |
| `F` | CF₃ | |
| `Q`、`y` | Boc | |
| `H` | Cbz | |
| `o` | OH | ● |
| `O` | O | ● |
| `q` | OMe | ● |
| `n`、`w` | NH₂ | ● |
| `N` | N | ● |
| `9` | N₃ | ● |
| `s` | SH | ● |
| `S` | SiH₃ | ● |
| `p` | PH₂ | ● |
| `f` | F | ● |
| `C`、`l` | Cl | ● |
| `b` | Br | ● |
| `i`、`I` | I | ● |
| `h` | H | ● |
| `d` | D | ● |

| `L` | Li | ● |

| `+`、`=` | 電荷を +1 | |
| `-` | 電荷を −1 | |

- ヘテロ原子で始まる基（`o`、`n` など）は、対象の原子をその元素に置き換えます（炭素の上で `o` を押すと、その炭素が OH の O になる）。
- 炭素で始まる骨格（環、`e`、`A`、`Q` など）は、対象の原子の元素を変えません（N の上で `a` を押すとピリジン）。
- 環のキーを続けて押すと、直前に描いた環の続きに環が描かれます。

#### 結合キー

| キー | 結合への作用 | マウスで結合をホバー中に効くか |
| --- | --- | --- |
| `1` / `2` / `3` | 単結合 / 二重結合 / 三重結合（楔などの種類は外れる） | 効く |
| `w` | 楔（手前向き） | 効かない（N が置かれる） |
| `W` | 破線楔（奥向き） | 効く |
| `h` | 破線楔（奥向き） | 効かない（H が置かれる） |
| `H` | 太線 | 効く |
| `b`、`B` | 太線 | 効かない（Br、B が置かれる） |
| `d` | 破線 | 効かない（D が置かれる） |
| `D` | 破線 | 効く |
| `y` | 波線 | 効く |
| `a`、`A` | ベンゼン環を縮環（結合を 1 辺として共有） | 効く |
| `v` | 三員環を縮環 | 効く |
| `4`〜`8` | 四〜八員環を縮環 | 効く |

キーの割り当ては、アプリを起動したフォルダに `chembuilder_config.json` を置くと変えられます。上の表は既定の割り当てです。

### 2.4 選択ツール

#### マウス

| 操作 | 条件 | 効果 |
| --- | --- | --- |
| クリック | 原子・結合・オブジェクトの上 | 選択に加える。選択済みなら外す（修飾キーなしで追加になる） |
| クリック | 何もない所 | 選択を解除 |
| ダブルクリック | 原子・結合の上 | つながっている分子全体を選択 |
| ダブルクリック | テキスト、括弧のラベルの上 | テキストの入力欄を開く |
| ダブルクリック | 反応表のセルの上 | セルの入力欄を開く |
| ドラッグ | 原子の上から | その原子を移動。選択に含まれる原子なら選択全体を移動 |
| ドラッグ | オブジェクトの上から | そのオブジェクトを移動。選択に含まれていれば選択全体を移動 |
| ドラッグ | 矢印 1 本だけを選択中、その端から | 矢印の端を動かす。向きは 15° 刻み |
| `Shift`+ドラッグ | 同上 | 矢印の端を自由な向きに動かす |
| ドラッグ | 何もない所から | 囲んで選択（投げ縄）。前の選択は置き換わる |
| `Alt`+ドラッグ | 原子を 1 個以上選択中（どこから始めてもよい） | 選択を重心のまわりに自由な角度で回転 |
| 回転ハンドルをドラッグ | 原子を 2 個以上選択中（選択の上に丸いハンドルが出る） | 選択を 15° 刻みで回転 |
| 回転ハンドルを `Shift`+ドラッグ | 同上 | 自由な角度で回転 |
| 回転ハンドルをダブルクリック | 同上 | 角度の入力欄を開く |
| 反転ボタンをクリック | ハンドルの左にボタンが出ているとき（選択の内と外をつなぐ結合が 1 本） | 選択を反転（`Ctrl`+`Shift`+`F` と同じ） |

#### キー

| キー | 条件 | 効果 |
| --- | --- | --- |
| `Delete` / `Backspace` | 選択あり | 選択した原子・結合・オブジェクトを削除 |
| `Delete` / `Backspace` | 選択なし | 結合ツールと同じ（ホバーまたはキーボードの対象を削除） |
| `Enter` | 原子をホバー中 | その原子をホットスポットにする |
| `g`、`G` | 原子をホバー中、またはホットスポットあり | その原子をホットスポットにし、選択にも加える |
| `Space`、`Tab` | | ホットスポットと結合ターゲットを解除 |
| 矢印キー | ホットスポットあり | その方向の隣の原子にホットスポットを移す |
| `Ctrl`+矢印キー、`Shift`+矢印キー | 原子を選択中 | 選択した原子を結合 1 本ぶん移動 |
| `Alt`+`→` / `Alt`+`←` | 原子を選択中 | 選択した原子を時計回り / 反時計回りに 15° 回転 |
| [原子キー](#原子キー) | 原子をホバー中、またはホットスポットあり | その原子に適用 |

選択ツールでは次のキーは効きません: [結合キー](#結合キー)、`x`（ラベルの展開）、`` ` ``（ラベルの入力欄）、`Shift`+矢印キーでの結合ターゲット、何もない所での元素を置くキー。

### 2.5 消しゴム、矢印ツール、テキストツール

| ツール | 操作 | 条件 | 効果 |
| --- | --- | --- | --- |

### 2.6 入力欄

入力欄が開いている間は、キャンバスのツールのキーとマウス操作は止まります。

| 入力欄 | 開き方 | 確定 | 取り消し | そのほか |
| --- | --- | --- | --- | --- |
| 原子のラベル | 結合ツールで `` ` `` | `Enter`、または欄の外をクリック | `Esc` | 欄の外のクリックは確定だけに使われ、原子は置かれない |
| テキスト | テキストツールでクリック、選択ツールでダブルクリック | `Enter`、または欄の外をクリック | `Esc` | `Shift`+`Enter` で改行。`Ctrl`+`G` で Symbol フォント（ギリシャ文字）の入 / 切。ツールバーの書式の部分のクリックは入力の続きとして扱われる |
| 反応表のセル | 選択ツールでセルをダブルクリック | `Enter`、または欄の外をクリック | `Esc` | 読み取れない値のときは `Enter` で確定されず、欄が残る |
| 回転の角度 | `Ctrl`+`R`、回転ハンドルをダブルクリック、メニュー「構造」→「回転」 | `Enter`（角度の分だけ回転。正の値が時計回り） | `Esc`、または欄の外をクリック | 数値でないときは `Enter` を押しても欄が残る。小数、負の値、全角数字も可 |

ラベルとテキストの中では、`_2` で下付き、`^+` で上付き、`**…**` で太字、`//…//` で斜体になります。

#### 式

選択・繰り返し・個別に移動・属性を設定・式のノードは式を受け付けます。例: `30*i + 5*sin(i)`、`layer % 2 == 0 && z > 0`。

- 演算子: `+ - * / % ^`（`%` は除数の符号、`^` はべき乗）、比較 `< <= > >= == !=`、`&& || !`、`c ? a : b`。真は 1、偽は 0。
- 関数: `sin cos tan asin acos atan`（ラジアン）、`sind cosd tand`（度）、`atan2 sqrt abs floor ceil round min max pow clamp sign rad deg`。定数 `pi`、`e`。
- 名前: ノード自身の変数（他のノードをつなげる入力）、分子の属性（`ring`・`layer`・`row`・`cell`、繰り返しノードで付けた名前、合流後の `input`、複製ノードの後の `copy`・`copies`、属性を設定ノードで付けたもの）、`k`（集合の中での番号）、`count`、`comp`（単量体の番号、0 から）、`x y z`（重心）、`i`・`n`（`copy`・`copies`）。繰り返しノードでは `i` がコピー番号、`n` がコピー数です。
- 数値欄には名前を含まない式（`360/7` など）も入力できます。
- ワイヤがつながっていない入力は、ノード上の入力欄に値が表示されます（ズーム 60 % 以上）。欄を左右にドラッグすると値が変わり、3 つの数値の欄は左右で x、上下で y（`Shift` を押しながらで z）が変わります。`Ctrl` で細かく動きます。1 回のドラッグが元に戻す 1 回分です。クリックすると数値か上のような式（3 つの数値はカンマ区切り、1 つなら 3 つ共通）を入力でき、Enter で確定、Esc で元に戻します。

#### カーブ・点・インデックス

- **円**: 原点を中心に xy 平面に「分割数」個の点を持つ閉じたカーブを作ります。
- **カーブを点に**: カーブに沿って点を置きます。等間隔に「個数」個、「間隔」Å ごと、またはカーブ自身の点から選べます。各点はカーブに沿って向き、x 軸がカーブの向き、z 軸がカーブの面の法線になります。
- **点にインスタンス**: 「インスタンス」に入力した分子のコピーを各点に置きます。「回転」で回してから、「点の向きに合わせる」がオンなら点の向きに回します。「選択」が 0 の点には置きません。コピーには点のインデックスが属性 `point` として付きます。
- **インデックス**: 要素ごとの値（0 からの番号）を与えます。点にインスタンスでは点の、選択・個別に移動・属性を設定では分子の番号です。式や XYZ 合成のノードにつなぐと、その出力も要素ごとの値になります（ワイヤに ƒ と表示）。全体で 1 つの値を取る入力につなぐとエラーになります。例: インデックス → 式 `a % 3 == 0` → 「選択」で 3 点おきに置き、インデックス → 式 `10 * a` → XYZ 合成の z → 「回転」でコピーを 1 つごとに 10° ずつ回します。

#### 自作ノード

`Ctrl`+`G` で作った自作ノードは集合体ファイルに保存されるので、どこで開いても同じになります。「自作ノード」欄のメニューから、ライブラリ（ユーザー設定フォルダの `OpenDrawChemistry/assembly_nodes`）への保存（他の集合体から追加できます）と `.odnode` ファイルへの書き出しができます。ライブラリの版と集合体の版が違うときは、どちらが変わったかを表示し、ライブラリの版を使うか別のコピーにするかを選べます。

| UI の倍率（`+`、`-`、`0`） | `Cmd` |
| 3D ビュー・集合体ビューの 元に戻す / やり直す | `Cmd` |
| 3D ビューの削除選択（クリック、ドラッグ）と、結合を 15° ずつ回すホイール | `Cmd` |
| 2D エディタのコピー・貼り付け、テキスト入力欄の Symbol フォント（`G`） | `Cmd` |
| 2D エディタの 元に戻す / やり直す、全体表示（`0`）、ツール切り替え（`1` / `2` / `3`）、整形（`K`）、回転（`R`）、反転（`Shift`+`F`）、選択の移動（矢印キー） | `Control` |

このため macOS では、図の全体表示（`Control`+`0`）と UI 倍率のリセット（`Cmd`+`0`）は別のキーになります。

## 8. 操作体系の込み入っている点

事実だけを並べます。

### 8.1 同じ操作が、画面・ツール・状態で別の意味になるもの

| 操作 | 場所ごとの意味 |
| --- | --- |
| `Shift`+ドラッグ | 3D: 視点の移動。ただし分子が 2 つ以上あって分子の上から始めると、その分子の移動。集合体: 視点の移動。ただし手動配置の分子を選択中は、どこから始めてもその分子の移動。2D 選択ツール: 回転ハンドルや矢印の端では、15° 刻みの解除。2D 矢印ツール: 15° 刻みの解除 |
| `Alt`+ドラッグ | 2D 選択ツール: 選択の回転。3D: 分子の上から始めると分子の回転、それ以外は視点の回転。集合体: 選択中の手動配置の分子の回転 |
| `Ctrl`+ドラッグ | 3D: 矩形での削除選択。ほかの画面では修飾キーなしと同じ |
| `Ctrl`+`0` | 2D: 図の全体表示と UI 倍率のリセットが同時に起こる。3D・集合体: UI 倍率のリセットだけ |
| `Ctrl`+`Z` | 2D: 図の編集。3D: 3D の編集。集合体: 集合体の編集。テキスト・表のセル・角度の入力欄: 欄の中の入力。ラベルの入力欄とほかのパネルの入力欄（2D の表示中）: 図の編集 |
| メニュー・ツールバーの「元に戻す」 | 集合体ビューでは集合体。3D ビューでは、見えていない 2D の図（キーの `Ctrl`+`Z` とは対象が違う） |
| `Delete` | 2D 結合ツール・矢印ツール: ホバーしているもの（選択は消えない）。2D 選択ツール: 選択、なければホバーしているもの。3D: 削除選択、なければピック。集合体: 効かない |
| クリック | 2D 結合ツール: 描く。2D 選択ツール: 選択の追加・解除。3D: ピック（測定用）。集合体: 分子の選択、測定モードでは原子のピック |
| ダブルクリック | 2D 選択ツール: 分子全体の選択、テキストやセルの編集、回転ハンドルでは角度の入力欄。3D・集合体のビューア: 視点を元に戻す。集合体のパネル: 名前の変更。スキャンのグラフ: 表示範囲を元に戻す |
| 右クリック | 2D: メニュー。3D: 原子の固定。集合体: なし |
| 右ドラッグ | 3D・集合体: 視点の移動。スキャンのグラフ: 囲んだ範囲の拡大。2D: なし |
| ホイール | 2D・3D・集合体: 拡大・縮小。3D で回転できる結合をピック中: 結合の回転。スキャンのグラフ: スクロール（拡大は `Ctrl`+ホイール） |
| `Shift`（刻みを変える） | 2D の回転ハンドルと矢印: 15° 刻みを外して自由に。3D のホイールでの結合の回転: 5° を 1° に。数値欄のドラッグ: 細かく |
| `Ctrl`+ホイール | 2D: 拡大・縮小。3D で結合をピック中: 15° ずつ回転。スキャンのグラフ: 拡大・縮小 |
| 矢印キー | 2D 結合ツール: ホットスポットの移動、ホットスポットがなければ原子を置く位置の移動。2D 選択ツール: ホットスポットの移動だけ |
| `Shift`+矢印キー | 2D 結合ツール: 結合ターゲットを決める。2D 選択ツール: 選択の移動 |
| `g` | 2D 結合ツール: ホバー中の原子をホットスポットに。2D 選択ツール: ホットスポットにして選択にも加える（ホバーがなくても効く） |
| `w`、`h`、`b`、`B`、`d`、`9` | 原子の上: NH₂、H、Br、BH₂、D、N₃。結合ターゲット（キーボード）: 楔、破線楔、太線、太線、破線、九員環。マウスで結合をホバー中・何もない所: 原子を 1 個置く |
| `a`、`1`〜`8`、`0`、`v`、`y`、`H` など | 原子の上と結合の上で別の作用（[原子キー](#原子キー)、[結合キー](#結合キー)） |
| `M` | 2D（原子の上）: MgBr。集合体: 測定モード |
| `Esc` | 2D: 入力欄の取り消し、囲み選択の中断（選択の解除はしない）。3D: ピックと削除選択の解除。集合体: 向き合わせ、測定モード、選択の順にやめる |
| `Enter` | 2D キャンバス: ホバー中の原子をホットスポットに。入力欄: 確定 |
| `Tab` | 2D キャンバス: ホットスポットの解除 |
| `Ctrl`+`X` | 2D キャンバス: コピー（切り取らない）。文字入力欄: 切り取り |

### 8.5 メニューにもツールチップにも表記のない操作

- `Ctrl`+`K`（整形。メニューの項目はあるがキーの表記がない）、`Ctrl`+`Shift`+`K`（反応式の整形。メニューの項目もない）
- `Ctrl`+`1` / `2` / `3`（ツールの切り替え）
- `Ctrl`+`Shift`+`Z`（やり直し。表記は `Ctrl`+`Y` だけ）
- `Ctrl`+`+` / `-`（UI の倍率）
- `Ctrl`+`X` がキャンバスではコピーになること
- 原子キー、結合キー、`x`、`` ` ``、`Enter`、`g`、`Space`、`Tab`、矢印キー（「断片の管理」の使い方に `x` の説明があるだけ）
- 選択ツールの `Ctrl` / `Shift`+矢印キー、`Alt`+`←` / `→`、`Alt`+ドラッグ
- 回転ハンドルのダブルクリック、`Shift` での刻みの解除
- 2D の中ドラッグでの移動
- タブの中クリックで閉じる
- 3D・集合体の右ドラッグ・中ドラッグでの移動
- スキャンのグラフの右ドラッグ、軸のドラッグ、`Ctrl`+ホイール

### 8.6 文字入力中でもキャンバスに届くキー（2D の表示中）

`Ctrl`+`1` / `2` / `3`、`Ctrl`+`K`、`Ctrl`+`Shift`+`K` は、どの入力欄にカーソルがあってもキャンバスに効きます。`Ctrl`+`Z` と `Ctrl`+`Y` は、ラベルの入力欄と、ほかのパネルの入力欄（断片の名前、元素記号など）にカーソルがある間もキャンバスの編集を戻します。`Ctrl`+`N` / `O` / `S` / `W` はどの欄にカーソルがあっても効きます。

## 9. 未確認の点

- 全体として、実機での確認はしていません（コードの読み取りだけです）。
- macOS の節は、UI ライブラリ（egui）のキーの扱いからの読み取りです。
- マウスで結合をホバーしているときに `w`、`h`、`b`、`B`、`d`、`9` が結合キーとして働かず原子が置かれる、という点は、コード上の判定順からの読み取りです。
- 選択ツールでの原子キーと、`Ctrl` / `Shift` / `Alt`+矢印キーでの移動・回転が、1 回ずつ「元に戻す」で戻るかどうか。
- ドラッグ中に `Esc` を押したときの動作は、囲み選択の中断だけを確認しました。原子の移動や回転の途中で押したときの動作は確かめていません。
- 2D キャンバスの `Tab` が、ホットスポットの解除と同時に入力欄へのフォーカス移動も起こすかどうか。
- 3D ビューで原子をダブルクリックしたときの動作。
- パラメータスキャンのグラフの操作（点のクリック以外）と、数値欄の操作は、UI ライブラリの既定の動作からの読み取りです。
- 日本語入力（IME）が有効な間の文字キーの動作。
